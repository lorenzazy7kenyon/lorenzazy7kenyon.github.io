科学上网详细教程（客户端导入订阅）

从首页复制对应格式的订阅链接后，按下面的步骤导入到客户端即可。

Clash（Windows / Mac）

  • 下载 Clash 客户端：Clash for Windows
  • 打开 Profiles（配置）页面 → 粘贴首页的 Clash 订阅链接（.yaml） → Update 更新
  • 选中节点后开启 System Proxy/系统代理即可

Clash Meta / mihomo（Android）

  • 下载 Clash Meta for Android 或 Clash for Android
  • 配置 → 新建配置 → URL 方式 → 粘贴 Clash 订阅链接
  • 选择节点并启动

V2ray（Windows / Android）

  • Windows：v2rayN；Android：v2rayNG
  • 订阅分组 → 添加订阅 → 粘贴 V2ray 订阅链接（.txt） → 更新订阅
  • 使用默认路由设置即可一键分流

iOS

  • Shadowrocket（小火箭）：配置 → 添加订阅 → 粘贴 V2ray 或 Clash 链接
  • Sing-box：Sing-box → Profiles → Import URL，使用 Sing-box 订阅链接（.json）（需美区 AppleID）
  • Quantumult X / Stash：同样支持导入 Clash 订阅链接

常见问题

  • 节点提示失效/超时：免费节点时效性短，前往首页获取最新更新时间的订阅链接并重新更新。
  • 延迟高：在"自动选择"分组中会自动切换到低延迟节点，或手动测速选择。
  • 订阅无法下载：部分运营商屏蔽 GitHub Pages，可开启后重试或使用镜像加速。
