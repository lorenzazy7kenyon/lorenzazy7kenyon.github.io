科学上网详细教程（客户端导入订阅）

从首页复制对应格式的订阅链接后，按下面的步骤导入到客户端即可。

Clash（Windows / Mac）

  • 下载 Clash 客户端：Clash for Windows
  • Profiles（配置）页面 → 粘贴 Clash 订阅链接（.yaml） → Update 更新
  • 选中节点后开启 System Proxy/系统代理即可

Clash Meta / mihomo（Android）

  • 下载 Clash Meta for Android
  • 配置 → 新建配置 → URL 方式 → 粘贴 Clash 订阅链接 → 选择节点并启动

V2ray（Windows / Android）

  • Windows：v2rayN；Android：v2rayNG
  • 订阅分组 → 添加订阅 → 粘贴 V2ray 订阅链接（.txt） → 更新订阅

iOS

  • Shadowrocket（小火箭）：配置 → 添加订阅 → 粘贴 V2ray 或 Clash 链接（美区 AppleID）
  • Sing-box：Profiles → Import URL，使用 Sing-box 订阅链接（.json）

常见问题

  • 节点提示失效/超时：免费节点时效性短，前往首页获取最新订阅并重新更新。
  • 延迟高：使用「自动选择」分组，或手动测速切换低延迟节点。
  • 订阅无法下载：GitHub Pages 可能被部分运营商屏蔽，开启代理后重试。
